Penting: Admin Panel ini hanya untuk admin. Private Key dipakai di browser untuk menandatangani token dan tidak disimpan oleh halaman ini. Jangan menyimpan Private Key di GitHub, APK, atau halaman publik. Untuk keamanan produksi, lindungi folder /admin/ dengan autentikasi hosting/server.

1. Kunci Digital

Buat sekali. Public Key harus dipasang ke APK. Private Key disimpan offline oleh admin.

Jika APK sudah menggunakan Public Key tertentu, jangan membuat pasangan baru tanpa membangun APK baru.

2. Buat Token

Lakukan setelah pembayaran QRIS diverifikasi.

3. Token Pembeli

Kirim token hanya kepada email pembeli yang sudah diverifikasi.

Token belum dibuat.

4. Alur

Pembeli bayar QRIS di payment.html → kirim bukti → admin verifikasi → admin membuat token → token dikirim ke email → pembeli login dengan email yang sama → masukkan token di aplikasi → APK memverifikasi signature + email + masa berlaku → Premium aktif.
